Privacy Policy

Last Updated: December 18, 2025

1. Introduction

PDF Library ("we", "our", or "the Extension") is a Chrome Extension designed to help users manage and read PDF files stored on their local device. We are committed to protecting your privacy. This policy explains what data we handle and how it is treated.

2. Data Collection and Usage

We do not collect, store, or transmit any of your personal data or file content to external servers.

  • Local Processing: All PDF processing, rendering, and management happens entirely within your browser on your local machine using the File System Access API.
  • No Cloud Uploads: Your PDF files never leave your computer. The Extension does not have a backend server.

3. Permissions and Data Storage

To function correctly, the Extension utilizes specific browser permissions:

  • Storage Permission: We use chrome.storage.local to save reading progress (e.g., page numbers). This data is stored locally on your device.
  • File Access: We only access folders you explicitly select via the "Add Directory" feature to list and display PDF files.
  • IndexedDB: Used to store file handles so you can access your library across browser sessions.

4. Third-Party Services

  • PDF.js: Used for rendering PDFs locally.
  • Analytics: This extension does not use Google Analytics or tracking pixels.

5. Contact

If you have any questions, please contact us via the support section on the Chrome Web Store.
