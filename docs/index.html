Why use PDF Library?

Privacy First

We use the File System Access API. Your files never leave your computer. No servers, no tracking.

Auto-Save Progress

Stop scrolling to find your place. The extension remembers the last page you read for every file.

Local Bookshelf

Add entire directories to create a visual library. Organize your papers, books, and documents.

Fast & Lightweight

Built with React and Tailwind. It's designed to be instant and resource-efficient.
